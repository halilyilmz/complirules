CryptoShredder

KVKK Md. 7 ve GDPR Art. 17 unutulma hakkı için kullanıcı bazlı AES-256-GCM anahtarlarını imha ederek RDBMS/log kayıtlarını anında kurtarılamaz hale getirir.

import { CryptoShredder } from '@complirules/primitives'

EprivacyConsentGate

import { EprivacyConsentGate } from '@complirules/primitives'

TransferImpactAssessment

import { TransferImpactAssessment } from '@complirules/primitives'
👤

BIPABiometricGuard

Illinois BIPA (740 ILCS 14/) uyarınca yüz tanıma veya parmak izi taramasından önce yazılı bilgilendirilmiş rıza doğrulaması yapar ($1K-$5K ceza koruması).

import { BIPABiometricGuard } from '@complirules/primitives'

JurisdictionConflictResolver

GDPR unutulma talebi ile yerel vergi (VUK Md. 253 5 yıl) veya sağlık saklama yükümlülüğü çakıştığında veriyi silmeyip yalıtılmış karantinaya alır.

import { JurisdictionConflictResolver } from '@complirules/primitives'

DifferentialPrivacyNoise

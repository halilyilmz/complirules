Nasıl Çalışır?

Karmaşık hukuki süreçleri 3 basit adıma indirger.

ADIM 01

Tek Komutla Kurun

Proje klasörünüzde npx complirules init çalıştırın. Stack'iniz (Next.js, Django vb.) otomatik tanınır.

ADIM 02

Ajanınız Kuralları Öğrenir

Cursor, Claude Code veya Windsurf, oluşturulan .cursor/rules/*.mdc kurallarını otomatik olarak bağlamına alır.

Yasal Sınırlar Korunur

Yapay zeka yasaklı veri toplama veya sızıntı yapacak kod yazamaz; yazmaya kalkarsa uyarılıp güvenli alternatife yönlendirilir.

# 🛡️ CompliRules: Compliance-as-Code & Legal AI Guardrail Engine

> **The open-source legal guardrail engine, deterministic static analyzer (linter), and Model Context Protocol (MCP) server that protects "Vibe Coders" and engineering teams from statutory privacy fines, data breach liabilities, and dark patterns.**

CompliRules guarantees that code generated by AI coding assistants (**Cursor, Claude Code, Windsurf, GitHub Copilot**) strictly adheres to international statutory frameworks and landmark judicial precedents (**KVKK, GDPR, EAA 2025 / WCAG 2.1 AA, HIPAA, CCPA/CPRA, FTC Health Safeguards, EU AI Act**).

---

## ⚡ Quick Start

### 1. Initialize CompliRules in Your Project
```bash
# Automatic setup for your project stack:
npx complirules init

# Target specific jurisdictions (e.g. EU & US):
npx complirules init --jurisdiction EU,US

# Install all global regulatory packs:
npx complirules init --all
```

This command automatically inspects your tech stack (Next.js, Prisma, Express, Django, etc.) and:
- Injects `.cursor/rules/*.mdc` rule definitions with RFC 2119 invariants (`MUST`, `NEVER`).
- Generates **`AGENTS.md`** and **`CLAUDE.md`** for Claude Code, Windsurf, and Copilot.
- Configures `.cursor/mcp.json` to connect the live Model Context Protocol server.

---

### 2. Audit Your Codebase (CI/CD Static Linter)
```bash
# Runs deterministic AST and regex scans across your codebase:
npx complirules check

# Scan a specific directory or file:
npx complirules check ./src
```

---

### 3. Generate Statutory RoPA & VERBİS Inventories
```bash
# Automatically derives a GDPR Article 30 (RoPA) & KVKK VERBİS table from your database schema:
npx complirules ropa prisma/schema.prisma
```

---

### 4. Scaffold Production Compliance Primitives
```bash
# Scaffold deterministic cryptographic user shredding and anonymization:
npx complirules scaffold crypto-shredding

# Scaffold a zero-PII structured logger with automatic redaction:
npx complirules scaffold pii-logger
```

## 🔌 Model Context Protocol (MCP) Server

CompliRules equips AI coding models with direct real-time reasoning tools via the **Model Context Protocol (MCP)**. When you run `complirules init`, your `.cursor/mcp.json` is configured automatically:

```json
{
  "mcpServers": {
    "complirules": {
      "command": "npx",
      "args": ["@complirules/mcp-server"]
    }
  }
}
```

### Registered MCP Tools:
1. **`verify_schema_compliance`:** Audits Prisma, Drizzle, or SQL schemas against statutory retention and cascade delete rules.
2. **`audit_code_pii`:** Inspects source code in real time for raw credential, national ID, or PII/PHI telemetry leakage.
3. **`check_ui_dark_patterns`:** Flags pre-ticked checkboxes, bundled consents, and missing accessible names.
4. **`generate_ropa_inventory`:** Generates comprehensive 10-column RoPA and VERBİS tables from database schemas.
5. **`lookup_legal_citation`:** Queries official statutory articles, judicial precedents, and regulatory fines.
6. **`lookup_active_partner`:** Dynamically queries community-vetted penetration testing (pentest) and compliance partners with exclusive community discounts.

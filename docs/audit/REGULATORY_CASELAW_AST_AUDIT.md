## A.1 Remote Asset Hotlinking & Dynamic IP Leaks (Google Fonts, CDNJS, Unpkg)

### 1. Legal Basis & Landmark Precedents
* **Statutory Clauses:** GDPR Article 6(1) (Lawfulness of processing), Article 44+ (General principle for transfers).
* **Judicial Precedents:**
  * **Court of Justice of the European Union (CJEU):** *Patrick Breyer v. Bundesrepublik Deutschland* (Case C-582/14, 19 October 2016). The CJEU ruled that dynamic IP addresses constitute personal data where an operator has legal means to identify the visitor.
  * **Landgericht München I (District Court of Munich):** Judgment of 20 January 2022, Docket No. **3 O 17493/20**.
* **Sanction / Fine:** The Munich court awarded statutory damages (€100) per affected claimant, imposed an injunction backed by a fine of up to **€250,000** for each repeat infraction under § 890 ZPO, and triggered a wave of hundreds of thousands of cease-and-desist letters across the DACH region. The court established that passing a user's dynamic IP address and HTTP Referer to Google's servers in the US via dynamic font calls without prior explicit consent is a per-se GDPR violation that cannot be justified under "legitimate interest" (Art. 6(1)(f)).

### 2. AI Code Anti-Pattern (Generated by Cursor / Claude)
AI agents routinely inject external stylesheet links or CDN script tags directly into the root HTML/JSX layout to quickly satisfy UI font or icon requests:

```html
<!-- Vulnerable: app/layout.tsx or index.html generated by AI Assistant -->
<html>
  <head>
    <!-- Leaks visitor dynamic IP and Referer header directly to Google LLC (US) -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
    
    <!-- External script hotlink leaking IP to Cloudflare/JSdelivr without SRI -->
    <script src="https://cdnjs.cloudflare.com/ajax/libs/lodash.js/4.17.21/lodash.min.js"></script>
  </head>
  <body>
    <!-- Client renders external avatar hotlink directly leaking IP to Automattic/Gravatar -->
    <img src="https://www.gravatar.com/avatar/205e460b479e2e5b48aec07710c08d50" alt="User Avatar" />
  </body>
</html>
```

### 3. Compliant Remediation Architecture
Web assets must either be self-hosted at build time (bundled statically within the application origin) or routed through a server-side signed reverse proxy that completely strips client IP addresses and client headers before outbound fetching.

```tsx
// Compliant: app/layout.tsx using Next.js local font bundling (Zero IP egress)
import { Inter } from 'next/font/google';
import Image from 'next/image';
import crypto from 'node:crypto';

// Next.js downloads Google fonts at build time and serves them strictly from the local origin
const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
});

// Production Signed Asset Proxy for external user media (Gravatar/Unsplash)
export function createSecureSignedProxyUrl(rawUrl: string, secretKey: string): string {
  const hmac = crypto.createHmac('sha256', secretKey);
  hmac.update(rawUrl);
  const signature = hmac.digest('hex');
  return `/api/assets/proxy?url=${encodeURIComponent(rawUrl)}&sig=${signature}`;
}

export default function RootLayout({ children }: { children: React.ReactNode }) {
  const safeAvatarUrl = createSecureSignedProxyUrl(
    'https://secure.gravatar.com/avatar/205e460b479e2e5b48aec07710c08d50',
    process.env.ASSET_PROXY_SECRET!
  );

  return (
    <html lang="en" className={inter.variable}>
      <head>
        {/* Strict Content Security Policy forbidding unapproved remote font/script hosts */}
        <meta
          httpEquiv="Content-Security-Policy"
          content="default-src 'self'; font-src 'self' data:; script-src 'self'; img-src 'self' data: /api/assets/proxy;"
        />
      </head>
      <body className="font-sans">
        <Image src={safeAvatarUrl} alt="Sanitized User Avatar" width={40} height={40} unoptimized />
        {children}
      </body>
    </html>
  );
}
```

```ts
// Compliant Server-Side Asset Proxy with SSRF Protection: app/api/assets/proxy/route.ts
import { NextRequest, NextResponse } from 'next/server';
import crypto from 'node:crypto';
import ipaddr from 'ipaddr.js';
import dns from 'node:dns/promises';

export async function GET(req: NextRequest) {
  const { searchParams } = new URL(req.url);
  const targetUrl = searchParams.get('url');
  const signature = searchParams.get('sig');

  if (!targetUrl || !signature) {
    return new NextResponse('Missing parameters', { status: 400 });
  }

  // 1. Verify cryptographic HMAC signature
  const hmac = crypto.createHmac('sha256', process.env.ASSET_PROXY_SECRET!);
  hmac.update(targetUrl);
  const expectedSig = hmac.digest('hex');
  if (!crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expectedSig))) {
    return new NextResponse('Invalid signature', { status: 403 });
  }

  const parsed = new URL(targetUrl);
  if (!['http:', 'https:'].includes(parsed.protocol)) {
    return new NextResponse('Invalid protocol', { status: 400 });
  }

  // 2. Strict SSRF check: Prevent access to internal private IP ranges
  const addresses = await dns.lookup(parsed.hostname, { all: true });
  for (const addr of addresses) {
    const ip = ipaddr.parse(addr.address);
    if (ip.range() !== 'unicast') {
      return new NextResponse('SSRF blocked: Private/Reserved IP target', { status: 403 });
    }
  }

  // 3. Fetch remote asset without forwarding user IP, Cookies, or Referer
  const upstreamRes = await fetch(targetUrl, {
    headers: {
      'User-Agent': 'CompliRules-PrivacyProxy/1.0',
    },
  });

  const blob = await upstreamRes.arrayBuffer();
  return new NextResponse(blob, {
    headers: {
      'Content-Type': upstreamRes.headers.get('Content-Type') || 'application/octet-stream',
      'Cache-Control': 'public, max-age=86400, immutable',
      'X-Content-Type-Options': 'nosniff',
    },
  });
}
```

## A.2 Third-Party Embeds & Joint Controllership (CJEU C-40/17 Fashion ID)

### 1. Legal Basis & Landmark Precedents
* **Statutory Clauses:** GDPR Article 26 (Joint Controllers), Article 6(1)(a) (Consent), ePrivacy Directive 2002/58/EC Article 5(3).
* **Judicial Precedent:**
  * **Court of Justice of the European Union (CJEU):** *Fashion ID GmbH & Co. KG v. Verbraucherzentrale NRW e.V.* (Case **C-40/17**, 29 July 2019).
* **Sanction / Fine:** The CJEU ruled that a website operator embedding a third-party social plugin (e.g., Facebook "Like" button) acts as a **joint controller** with Facebook regarding the collection and transmission of personal data (IP addresses and browser headers) triggered by loading the page, even if the visitor has no Facebook account or never clicks the button. Under GDPR Article 83(5), lack of a lawful basis for this transmission subjects operators to administrative fines up to **€20,000,000 or 4% of worldwide turnover**. In Germany and across the EU, this case mandates the **Two-Click Solution (Zwei-Klick-Lösung)**: zero third-party DOM execution without prior, affirmative interaction.

### 2. AI Code Anti-Pattern (Generated by Cursor / Claude)
AI agents generate embedded YouTube/Vimeo tutorials or Google Maps widgets using raw `<iframe>` elements that auto-fetch scripts, send cookies, and broadcast visitor telemetry immediately upon page load:

```tsx
// Vulnerable: components/LocationMap.tsx generated by AI Assistant
export function LocationMap() {
  return (
    <div className="w-full h-96">
      {/* Violates CJEU C-40/17: Executes immediately, transmitting visitor IP and cookies to Google */}
      <iframe
        src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d2428.4!2d13.4!3d52.5..."
        width="100%"
        height="100%"
        style={{ border: 0 }}
        loading="lazy"
        allowFullScreen
      />
    </div>
  );
}
```

### 3. Compliant Remediation Architecture
Implement the W3C/EDPB-approved **Two-Click Solution**. The application renders an inert local placeholder with an explicit privacy notice. The external `<iframe>` is only mounted into the DOM after affirmative, explicit user consent.

```tsx
// Compliant: components/TwoClickEmbed.tsx
'use client';

import React, { useState, useEffect } from 'react';

interface TwoClickEmbedProps {
  providerName: 'YouTube' | 'Google Maps' | 'Vimeo';
  embedSrc: string;
  privacyPolicyUrl: string;
  thumbnailPlaceholderUrl?: string;
  title: string;
}

export function TwoClickEmbed({
  providerName,
  embedSrc,
  privacyPolicyUrl,
  thumbnailPlaceholderUrl,
  title,
}: TwoClickEmbedProps) {
  const [hasConsented, setHasConsented] = useState<boolean>(false);
  const consentStorageKey = `complirules_consent_embed_${providerName.toLowerCase().replace(/\s+/g, '_')}`;

  useEffect(() => {
    // Check if user previously granted persistent category consent
    const stored = localStorage.getItem(consentStorageKey);
    if (stored === 'granted') {
      setHasConsented(true);
    }
  }, [consentStorageKey]);

  const handleActivate = (persistChoice: boolean) => {
    if (persistChoice) {
      localStorage.setItem(consentStorageKey, 'granted');
    }
    setHasConsented(true);
  };

  if (hasConsented) {
    return (
      <div className="relative w-full h-full min-h-[350px] rounded-lg overflow-hidden border border-slate-700">
        <iframe
          src={embedSrc}
          title={title}
          className="w-full h-full absolute inset-0 border-0"
          allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
          allowFullScreen
          sandbox="allow-scripts allow-same-origin allow-presentation"
        />
      </div>
    );
  }

  return (
    <div
      role="region"
      aria-label={`${providerName} Privacy Notice`}
      className="relative w-full min-h-[350px] bg-slate-900 text-slate-100 rounded-lg flex flex-col items-center justify-center p-6 text-center border border-slate-800"
      style={
        thumbnailPlaceholderUrl
          ? { backgroundImage: `linear-gradient(rgba(15,23,42,0.85), rgba(15,23,42,0.85)), url(${thumbnailPlaceholderUrl})`, backgroundSize: 'cover' }
          : undefined
      }
    >
      <div className="max-w-md space-y-4">
        <div className="inline-flex p-3 bg-amber-500/10 text-amber-400 rounded-full">
          <svg className="w-8 h-8" fill="none" stroke="currentColor" viewBox="0 0 24 24">
            <path strokeLinecap="round" strokeLinejoin="round" strokeWidth="2" d="M12 9v2m0 4h.01m-6.938 4h13.856c1.54 0 2.502-1.667 1.732-3L13.732 4c-.77-1.333-2.694-1.333-3.464 0L3.34 16c-.77 1.333.192 3 1.732 3z" />
          </svg>
        </div>
        <h3 className="text-lg font-bold">External Content Blocked ({providerName})</h3>
        <p className="text-sm text-slate-300">
          Loading this content connects directly to {providerName}&apos;s servers. Your IP address, device telemetry, and browsing headers will be transmitted and processed under their{' '}
          <a
            href={privacyPolicyUrl}
            target="_blank"
            rel="noopener noreferrer"
            className="text-blue-400 underline hover:text-blue-300"
          >
            Privacy Policy
          </a>.
        </p>
        <div className="flex flex-col sm:flex-row gap-3 justify-center pt-2">
          <button
            type="button"
            onClick={() => handleActivate(false)}
            className="px-4 py-2 bg-blue-600 hover:bg-blue-700 text-white font-medium rounded-md focus:outline-none focus:ring-2 focus:ring-blue-500 focus:ring-offset-2 focus:ring-offset-slate-900"
          >
            Load Once
          </button>
          <button
            type="button"
            onClick={() => handleActivate(true)}
            className="px-4 py-2 bg-slate-800 hover:bg-slate-700 text-white font-medium rounded-md border border-slate-700 focus:outline-none focus:ring-2 focus:ring-slate-400 focus:ring-offset-2 focus:ring-offset-slate-900"
          >
            Always Allow {providerName}
          </button>
        </div>
      </div>
    </div>
  );
}
```

## A.3 Cookie Consent Architecture & Symmetrical Rejection (Planet49 & CNIL)

### 1. Legal Basis & Landmark Precedents
* **Statutory Clauses:** Directive 2002/58/EC Article 5(3); GDPR Article 4(11), Article 7(4).
* **Judicial Precedents:**
  * **Court of Justice of the European Union (CJEU):** *Planet49 GmbH* (Case **C-673/17**, 1 October 2019). Pre-ticked checkboxes do NOT constitute valid consent.
  * **French Data Protection Authority (CNIL):** Deliberations SAN-2021-023 (Google LLC: **€150,000,000**), SAN-2021-024 (Facebook: **€60,000,000**), SAN-2020-012 (Amazon: **€35,000,000**).
  * **Noyb (None of Your Business / Max Schrems):** Hundreds of mass complaints filed against cookie dark patterns across 2021–2023.
* **Sanction / Fine:** Total fines exceeding **€245M+**. The CNIL established that **rejecting cookies must be as easy as accepting them ("Refuser doit être aussi simple qu'accepter")**. Having an "Accept All" button on the first layer while forcing users into a multi-step "Manage Settings" screen to reject constitutes an illegal dark pattern.

### 2. AI Code Anti-Pattern (Generated by Cursor / Claude)
AI agents invariably create asymmetrical cookie banners where the "Accept" button is a prominent primary call-to-action, while "Reject" is omitted or hidden behind a tiny, deceptive configuration link:

```tsx
// Vulnerable: components/CookieBanner.tsx generated by AI Assistant
export function VulnerableCookieBanner() {
  return (
    <div className="fixed bottom-0 p-4 bg-gray-900 text-white flex justify-between">
      <p>We use cookies to improve your experience. By continuing, you agree to our use of cookies.</p>
      <div className="flex gap-2">
        {/* Dark Pattern: No symmetrical 'Reject All' button. Pre-ticks analytics consent */}
        <button onClick={() => setAllCookies(true)} className="bg-blue-600 px-4 py-2 rounded font-bold">
          Accept All
        </button>
        <button onClick={() => openSettingsModal()} className="text-xs text-gray-400 underline">
          Preferences
        </button>
      </div>
    </div>
  );
}
```

### 3. Compliant Remediation Architecture
Implement a fully symmetrical, multi-category Consent Management Provider (CMP) state machine where:
1. "Accept All" and "Reject All" are displayed on the **first layer** with **identical visual weight, size, and prominence**.
2. All non-essential categories (Analytics, Marketing) are **unchecked by default**.
3. Zero non-essential tracking cookies or scripts execute until explicit opt-in is recorded.

```tsx
// Compliant: components/SymmetricalCMPBanner.tsx
'use client';

import React, { useState, useEffect } from 'react';

export interface ConsentPreferences {
  necessary: true; // Invariant: Strictly necessary cookies cannot be disabled
  analytics: boolean;
  marketing: boolean;
  timestamp: string;
  version: number;
}

const CMP_VERSION = 2;
const CONSENT_STORAGE_KEY = 'complirules_user_consent_v2';

export function SymmetricalCMPBanner() {
  const [isOpen, setIsOpen] = useState<boolean>(false);
  const [showDetails, setShowDetails] = useState<boolean>(false);
  const [analyticsChecked, setAnalyticsChecked] = useState<boolean>(false); // MUST default to false (Planet49)
  const [marketingChecked, setMarketingChecked] = useState<boolean>(false); // MUST default to false (Planet49)

  useEffect(() => {
    const rawConsent = localStorage.getItem(CONSENT_STORAGE_KEY);
    if (!rawConsent) {
      setIsOpen(true);
    } else {
      try {
        const parsed = JSON.parse(rawConsent) as ConsentPreferences;
        if (parsed.version !== CMP_VERSION) {
          setIsOpen(true); // Re-prompt on privacy policy version bump
        }
      } catch {
        setIsOpen(true);
      }
    }
  }, []);

  const saveConsent = (analytics: boolean, marketing: boolean) => {
    const consent: ConsentPreferences = {
      necessary: true,
      analytics,
      marketing,
      timestamp: new Date().toISOString(),
      version: CMP_VERSION,
    };
    localStorage.setItem(CONSENT_STORAGE_KEY, JSON.stringify(consent));
    setIsOpen(false);

    // Dispatch global custom event for script loaders
    window.dispatchEvent(new CustomEvent('complirules:consent-updated', { detail: consent }));
  };

  if (!isOpen) return null;

  return (
    <aside
      role="dialog"
      aria-modal="true"
      aria-labelledby="cmp-title"
      aria-describedby="cmp-desc"
      className="fixed bottom-0 inset-x-0 z-50 bg-slate-900 border-t border-slate-800 p-6 shadow-2xl text-slate-100"
    >
      <div className="max-w-5xl mx-auto flex flex-col gap-6">
        <div>
          <h2 id="cmp-title" className="text-xl font-bold tracking-tight">Your Privacy Choices</h2>
          <p id="cmp-desc" className="text-sm text-slate-300 mt-2">
            We use cookies to maintain security, analyze aggregated traffic, and deliver personalized marketing. In compliance with CJEU Planet49 and CNIL guidelines, non-essential cookies require your explicit consent before loading.
          </p>
        </div>

        {showDetails && (
          <div className="bg-slate-950 p-4 rounded-lg border border-slate-800 space-y-4">
            <div className="flex items-center justify-between">
              <div>
                <span className="font-semibold">Strictly Necessary Cookies</span>
                <p className="text-xs text-slate-400">Required for authentication, session security, and cart storage.</p>
              </div>
              <input type="checkbox" checked disabled className="cursor-not-allowed h-5 w-5 rounded accent-blue-500" />
            </div>

            <div className="flex items-center justify-between border-t border-slate-800 pt-3">
              <div>
                <label htmlFor="analytics-consent" className="font-semibold cursor-pointer">Analytics Cookies</label>
                <p className="text-xs text-slate-400">Measures aggregate site usage and performance.</p>
              </div>
              <input
                id="analytics-consent"
                type="checkbox"
                checked={analyticsChecked}
                onChange={(e) => setAnalyticsChecked(e.target.checked)}
                className="h-5 w-5 rounded accent-blue-500 cursor-pointer"
              />
            </div>

            <div className="flex items-center justify-between border-t border-slate-800 pt-3">
              <div>
                <label htmlFor="marketing-consent" className="font-semibold cursor-pointer">Marketing & Targeting</label>
                <p className="text-xs text-slate-400">Enables cross-context behavioral advertising and audience measurement.</p>
              </div>
              <input
                id="marketing-consent"
                type="checkbox"
                checked={marketingChecked}
                onChange={(e) => setMarketingChecked(e.target.checked)}
                className="h-5 w-5 rounded accent-blue-500 cursor-pointer"
              />
            </div>
          </div>
        )}

        {/* Symmetrical Layer 1 Buttons: Symmetrical geometry, font, and equal contrast */}
        <div className="flex flex-col sm:flex-row items-center justify-end gap-3">
          <button
            type="button"
            onClick={() => setShowDetails(!showDetails)}
            className="w-full sm:w-auto px-5 py-2.5 rounded-lg border border-slate-700 bg-slate-800 hover:bg-slate-700 text-sm font-semibold transition"
          >
            {showDetails ? 'Hide Options' : 'Customize Options…'}
          </button>
          <button
            type="button"
            onClick={() => saveConsent(false, false)}
            className="w-full sm:w-auto px-6 py-2.5 rounded-lg border border-slate-600 bg-slate-800 hover:bg-slate-700 text-white text-sm font-semibold transition focus:ring-2 focus:ring-blue-500"
          >
            Reject All
          </button>
          <button
            type="button"
            onClick={() => saveConsent(true, true)}
            className="w-full sm:w-auto px-6 py-2.5 rounded-lg border border-transparent bg-blue-600 hover:bg-blue-500 text-white text-sm font-semibold transition focus:ring-2 focus:ring-blue-500"
          >
            Accept All
          </button>
        </div>
      </div>
    </aside>
  );
```

## A.4 GDPR Article 20: Machine-Readable Data Portability Endpoint

### 1. Legal Basis & Landmark Precedents
* **Statutory Clauses:** GDPR Article 20 (Right to data portability), Article 12 (Transparent information, communication and modalities).
* **Judicial Precedents & Guidelines:**
  * **Article 29 Working Party / European Data Protection Board (EDPB):** *Guidelines on the Right to Data Portability (WP 242 rev.01)*.
  * **Italian Garante & Dutch AP Enforcement Actions (2020–2023):** Platforms penalizing users trying to migrate data to competitors were hit with fines under GDPR Art. 83(5) for restricting the right to receive personal data *"in a structured, commonly used and machine-readable format"*.
* **Sanction / Fine:** Non-compliance with Article 20 falls under the highest penalty tier: up to **€20,000,000 or 4% of total worldwide annual turnover**. A common developer oversight is providing an HTML/PDF download or omitting the feature entirely, which fails the "machine-readable" (JSON/CSV) standard.

### 2. AI Code Anti-Pattern (Generated by Cursor / Claude)

```ts
// Compliant: app/api/v1/user/data-portability/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';
import { verifyAuthSession } from '@/lib/auth';
import { Ratelimit } from '@upstash/ratelimit';
import { redis } from '@/lib/redis';

// Strict rate limit: Max 2 portability exports per 24 hours per user to prevent DoS/exfiltration
const portabilityLimiter = new Ratelimit({
  redis,
  limiter: Ratelimit.slidingWindow(2, '24 h'),
});

export async function GET(req: NextRequest) {

  if (!session?.userId) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  const { success } = await portabilityLimiter.limit(`dsr_export_${session.userId}`);
  if (!success) {
    return NextResponse.json(
      { error: 'Rate limit exceeded. Data portability dumps are limited to 2 requests per 24 hours.' },
      { status: 429 }
    );
  }

  // Retrieve all data generated by or attributed to the data subject
  const userData = await prisma.user.findUnique({
    where: { id: session.userId },
    select: {
      id: true,
      email: true,
      name: true,
      createdAt: true,
      updatedAt: true,
      profiles: true,
      orders: {
        include: { items: true, payments: true },
      },
      auditLogs: {
        where: { userId: session.userId },
        select: { action: true, ipAddress: false, createdAt: true }, // Sanitize internal security hashes
      },
      consents: true,
    },
  });

    return NextResponse.json({ error: 'User record not found' }, { status: 404 });

  const exportPayload = {
    $schema: 'https://complirules.org/schemas/gdpr-art20-portability-v1.json',

      generatedAt: new Date().toISOString(),

      dataSubjectId: session.userId,
      formatVersion: '1.0.0',
    },
    personalData: userData,
  };

  const jsonString = JSON.stringify(exportPayload, null, 2);

  return new NextResponse(jsonString, {
    status: 200,
    headers: {
      'Content-Type': 'application/json; charset=utf-8',
      'Content-Disposition': `attachment; filename="data-export-${session.userId}-${Date.now()}.json"`,
      'Cache-Control': 'no-store, no-cache, must-revalidate, private',

  });
```

### 1. Legal Basis & Landmark Precedents

* **Judicial Precedents:**

The EU DPAs explicitly ruled that even with IP anonymization (`anonymize_ip: true`), Google's client ID and browser fingerprint allow direct US intelligence access under the CLOUD Act. ### 3. Compliant Remediation Architecture

1. Strips the visitor's actual IP address.
2. Removes external identifiers and replaces the client ID with a rotating, salted HMAC token.
3. Scrubs the User-Agent header down to generic platform categories.
4. Drops query parameters containing potential PII or UTM strings before egress to third-party endpoints.

```ts
// Compliant: app/api/telemetry/proxy/route.ts (Server-Side Pseudonymization Engine)
import { NextRequest, NextResponse } from 'next/server';
import crypto from 'node:crypto';

export async function POST(req: NextRequest) {
  // 1. Verify consent state passed via secure cookie/header
  const consentCookie = req.cookies.get('complirules_user_consent_v2')?.value;
  if (!consentCookie || !JSON.parse(consentCookie).analytics) {
    return new NextResponse('Analytics consent not granted', { status: 403 });
  }

  const rawBody = await req.json();

  // 2. Generate ephemeral pseudonymized client ID (Salt rotated daily)
  const dailySalt = process.env.TELEMETRY_DAILY_SALT || 'default-secret-salt';
  const rawClientId = rawBody.clientId || req.ip || 'anonymous';
  const pseudonymizedClientId = crypto
    .createHmac('sha256', dailySalt)
    .update(rawClientId)
    .digest('hex');

  // 3. Construct sanitized event payload
  const sanitizedPayload = {
    client_id: pseudonymizedClientId,
    events: (rawBody.events || []).map((event: any) => ({
      name: event.name,
      params: {
        ...event.params,
        // Completely strip PII parameters
        page_location: event.params?.page_location?.split('?')[0], // Remove query string
        user_ip: '0.0.0.0', // Nullify IP
      },
    })),
  };

  // 4. Forward strictly from server-to-server (User IP is never transmitted across borders)
  const upstreamUrl = `https://www.google-analytics.com/mp/collect?measurement_id=${process.env.GA_MEASUREMENT_ID}&api_secret=${process.env.GA_API_SECRET}`;

  await fetch(upstreamUrl, {
    method: 'POST',
    body: JSON.stringify(sanitizedPayload),
    headers: {
      'Content-Type': 'application/json',
      'User-Agent': 'CompliRules-Telemetry-Proxy/2.0 (EU-Regulated)',
    },
  });

  return NextResponse.json({ status: 'telemetry_pseudonymized_and_dispatched' });
}
```

```ts
// Compliant: lib/monitoring/safe-sentry.ts
import * as Sentry from '@sentry/nextjs';

// Regex patterns for standard PII & medical record identifiers
const PHI_PATTERNS = {
  ssn: /\b\d{3}-\d{2}-\d{4}\b/g,
  mrn: /\bMRN[-:]?\s*\d{6,10}\b/gi,
  email: /\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b/g,
  phone: /\b\d{3}[-.]?\d{3}[-.]?\d{4}\b/g,
};

function redactPHIString(text: string): string {
  let cleaned = text;
  cleaned = cleaned.replace(PHI_PATTERNS.ssn, '[REDACTED-SSN]');
  cleaned = cleaned.replace(PHI_PATTERNS.mrn, '[REDACTED-MRN]');
  cleaned = cleaned.replace(PHI_PATTERNS.email, '[REDACTED-EMAIL]');
  cleaned = cleaned.replace(PHI_PATTERNS.phone, '[REDACTED-PHONE]');
  return cleaned;
}

        event.exception.values.forEach((exception) => {
          if (exception.value) {
            exception.value = redactPHIString(exception.value);
          }
        });
      }

      // 2. Strip request headers containing session cookies or patient tokens

        delete event.request.cookies;
        delete event.request.headers?.['authorization'];
        delete event.request.headers?.['cookie'];

          event.request.data = redactPHIString(event.request.data);
        }
      }

      // 3. Drop user identifiers unless they are non-identifiable internal system hashes
      if (event.user) {
        delete event.user.email;
        delete event.user.ip_address;
        delete event.user.username;
      }

      return event;
    },
  });
```

## B.4 Emergency Access "Break-Glass" Protocol (45 CFR § 164.312(a)(2)(ii))

### 1. Legal Basis & Landmark Precedents

* **Sanction / Clinical Risk:** Failure to establish emergency access procedures leaves hospital ICU or ER clinicians locked out of patient allergy, blood type, or surgical records during system outages or cross-department emergencies. Conversely, establishing an un-audited "backdoor" or permanent admin toggle violates § 164.312(b). ### 3. Compliant Remediation Architecture
Implement an enterprise-grade **Break-Glass Emergency Protocol**:
1. Requires explicit, documented clinical justification and an emergency code.
2. Issues a short-lived (e.g. 60-minute), cryptographically signed break-glass token.
3. Automatically notifies the hospital Privacy Officer / CISO via automated webhook.
4. Records an append-only, tamper-evident cryptographic HMAC audit record in an immutable table.

```ts
// Compliant: lib/auth/break-glass.ts
import { prisma } from '@/lib/prisma';
import crypto from 'node:crypto';

export interface BreakGlassRequest {
  physicianId: string;
  patientId: string;
  clinicalReason: string;
  emergencyType: 'CODE_BLUE' | 'TRAUMA_STAT' | 'SURGICAL_CRITICAL' | 'DISASTER_RESPONSE';
}

export interface BreakGlassSession {
  token: string;
  expiresAt: Date;
  auditId: string;
}

export async function initiateBreakGlassAccess(request: BreakGlassRequest): Promise<BreakGlassSession> {
  if (!request.clinicalReason || request.clinicalReason.trim().length < 15) {
    throw new Error('HIPAA § 164.312(a)(2)(ii) Violation: Detailed clinical justification is required for emergency override.');
  }

  const durationMinutes = 60;
  const expiresAt = new Date(Date.now() + durationMinutes * 60 * 1000);
  const rawToken = crypto.randomBytes(32).toString('hex');
  const tokenHash = crypto.createHash('sha256').update(rawToken).digest('hex');

  // 1. Immutable Audit Logging with Cryptographic Hash Chaining
  const latestLog = await prisma.breakGlassAuditLog.findFirst({
    orderBy: { createdAt: 'desc' },
  });
  const previousHash = latestLog?.recordHash || 'GENESIS_HEALTH_HASH';

  const logPayload = `${request.physicianId}:${request.patientId}:${request.emergencyType}:${request.clinicalReason}:${expiresAt.toISOString()}:${previousHash}`;
  const recordHash = crypto.createHmac('sha256', process.env.AUDIT_HMAC_SECRET!).update(logPayload).digest('hex');

  const auditRecord = await prisma.breakGlassAuditLog.create({
    data: {
      physicianId: request.physicianId,
      patientId: request.patientId,
      clinicalReason: request.clinicalReason,
      emergencyType: request.emergencyType,
      tokenHash,
      previousHash,
      recordHash,
      expiresAt,
    },
  });

  // 2. High-Priority Alert Dispatch to Privacy & Security Officers
  await dispatchEmergencySecurityAlert({
    event: 'HIPAA_BREAK_GLASS_TRIGGERED',
    physicianId: request.physicianId,
    patientId: request.patientId,
    reason: request.clinicalReason,
    auditId: auditRecord.id,
  });

  return {
    token: rawToken,
    expiresAt,
    auditId: auditRecord.id,
  };
}

async function dispatchEmergencySecurityAlert(alertData: any) {
  // Dispatches webhook to SIEM / PagerDuty / Security Operations Center
  if (process.env.SECURITY_WEBHOOK_URL) {
    await fetch(process.env.SECURITY_WEBHOOK_URL, {
      method: 'POST',
      body: JSON.stringify(alertData),
      headers: { 'Content-Type': 'application/json' },
    });
  }
}
```

## D.1 Article 5 Prohibited AI Practices (In Force 2 February 2025)

### 1. Legal Basis & Statutory Rules
* **Statutory Clauses:** 
  * Regulation (EU) 2024/1689 (EU Artificial Intelligence Act), **Article 5**: *Prohibited AI Practices*.
    * **Art. 5(1)(f)**: The placing on the market, the putting into service, or the use of AI systems to infer emotions of a natural person in the areas of **workplace and education institutions**.
    * **Art. 5(1)(e)**: Creating or expanding facial recognition databases through the **untargeted scraping of facial images from the internet or CCTV footage**.
    * **Art. 5(1)(c)**: AI-driven **social scoring** (evaluating trustworthiness based on social behavior or personality characteristics leading to detrimental treatment).
    * **Art. 5(1)(a)–(b)**: Subliminal, manipulative, or deceptive techniques subverting human autonomy.
* **Effective Date:** **2 February 2025** (6 months post-entry into force).
* **Sanction / Fine:** Article 99(3) prescribes the most severe penalty tier under EU law: administrative fines up to **€35,000,000 or 7% of total worldwide annual turnover** (whichever is higher). Deploying an emotion-detection model in HR recruiting software or scraping profile pictures for face embeddings exposes companies to immediate enforcement by national market surveillance authorities and the EU AI Office.

### 2. AI Code Anti-Pattern (Generated by Cursor / Claude)

```python
from typing import Dict, Any

    WORKPLACE_HR = "WORKPLACE_HR"
    EDUCATION = "EDUCATION"
    MEDICAL_DIAGNOSTIC = "MEDICAL_DIAGNOSTIC"

    """Raised when an AI operation violates EU AI Act Article 5."""
    pass

class AIActComplianceEnforcer:
    PROHIBITED_CAPABILITIES = {
        "EMOTION_RECOGNITION": [DomainContext.WORKPLACE_HR, DomainContext.EDUCATION],
        "UNTARGETED_FACIAL_SCRAPING": [DomainContext.WORKPLACE_HR, DomainContext.EDUCATION, DomainContext.ENTERTAINMENT],
        "SOCIAL_SCORING": [DomainContext.WORKPLACE_HR, DomainContext.EDUCATION],
    }

    @classmethod
    def validate_inference_request(cls, capability: str, context: DomainContext, metadata: Dict[str, Any]):
        # Article 5(1)(f): Absolute prohibition of emotion recognition in workplace & education
        if capability == "EMOTION_RECOGNITION" and context in cls.PROHIBITED_CAPABILITIES["EMOTION_RECOGNITION"]:

                f"FATAL: EU AI Act Article 5(1)(f) violation. Emotion recognition in context '{context}' "
                "is strictly prohibited under Regulation (EU) 2024/1689. Operation halted."
            )

        # Article 5(1)(e): Absolute prohibition of untargeted web scraping for facial recognition
        if capability == "UNTARGETED_FACIAL_SCRAPING":
            raise ProhibitedPracticeViolation(
                "FATAL: EU AI Act Article 5(1)(e) violation. Untargeted scraping of facial images "
                "from the internet or CCTV is an outlawed biometric practice."
            )

        return True

# Compliant HR Evaluation Engine (Skills-based, zero emotion analysis)
def evaluate_candidate_skills(technical_assessment_scores: Dict[str, float]) -> Dict[str, Any]:
```

## D.2 Article 50 Transparency Obligations & Synthetic Content Watermarking

### 1. Legal Basis & Statutory Rules
* **Statutory Clauses:** 
  * Regulation (EU) 2024/1689, **Article 50**: *Transparency obligations for providers and deployers of certain AI systems*.
    * **Art. 50(1)**: Providers shall ensure that AI systems intended to interact directly with natural persons are designed and developed in such a way that those persons are informed that they are interacting with an AI system (unless obvious from the context).
    * **Art. 50(2)**: Providers of AI systems (including general-purpose AI systems) generating synthetic audio, image, video, or text content shall ensure that the outputs are marked in a **machine-readable format and detectable as artificially generated or manipulated**.
    * **Art. 50(4)**: Deployers of an AI system that generates or manipulates image, audio, or video content constituting a **deepfake** shall disclose that the content has been artificially generated or manipulated.
* **Sanction / Fine:** Non-compliance with Article 50 subjects entities to administrative fines under Article 99(4) of up to **€15,000,000 or 3% of total worldwide annual turnover**.

### 2. AI Code Anti-Pattern (Generated by Cursor / Claude)
